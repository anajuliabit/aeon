## Symptom

`cost-report` fires on schedule and dies with `terminal_reason: api_error`,
`fast_mode_disabled_reason: sdk_opt_in_required`. Every subsequent
scheduled tick since 8-04 05:00Z has landed the same signature.

## Blast radius

Single-skill (cost-report). This is a chronic-cohort deepening rather than
a fleet event. Weekly cost visibility is blind while the skill is down —
last successful weekly report was 7-27.

## What was NOT affected

The other 17 ISS-029-affected skills recovered cleanly on the first
post-20:14Z-8-03 dispatch. Whatever gate flipped between 8-03 20:14Z and
8-04 05:00Z on the cost-report path is specific to cost-report's SDK
call shape (likely the fast-mode / permission-mode contract).

## Fix ownership

Investigate whether cost-report's SKILL.md (or its cron-runner config) sets
a Claude Code CLI flag that requires SDK opt-in and is no longer present
after the harness upgrade. Candidate fixes:

1. Add the required `--allow` / `--sdk-opt-in` flag (whichever the harness
   documents for the mode the skill needs) to the cost-report dispatch shape.
2. Rewrite cost-report to not depend on the disabled SDK mode.
3. Toggle the fast-mode opt-in default in aeon.yml or the workflow.
