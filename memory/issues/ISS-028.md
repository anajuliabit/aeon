## What happened

Multiple skills hit `bash -c 'cmd > file'` sandbox block starting 2026-07-22 in security-digest 14:42Z. Regression has recurred n=11+ times across 8 consecutive UTC-days (7-22 → 7-30) touching 6+ distinct skills. Every fire so far has been fully worked around via alternate paths — no data loss, no user-visible failure — but the underlying sandbox restriction is stable.

Skills confirmed to hit the block: security-digest, reg-monitor, agent-buzz, list-digest, heartbeat (writing notify file), morning-brief. Same-day peak was 7-29 with 4 fires (security-digest 14:42Z + reg-monitor + agent-buzz 17:37Z + list-digest 17:36Z).

## Investigation notes

Not a candidate for direct sandbox-config change (sandbox is inherited from GitHub Actions Claude Code runner). Fix path is skill-side discipline: update SKILL.md files for affected skills to prefer Write/Edit/curl-with-`-o` patterns explicitly, so LLM doesn't reach for `bash > file` on first attempt each fire.
