`monitor-polymarket` is disabled in `aeon.yml` and never writes to any log. The eval entry uses `memory/logs/*.md` with the pattern `### monitor-polymarket|## Polymarket|POLYMARKET`. The most recent log file (memory/logs/2026-06-21.md) contains lowercase "Polymarket" references from token-pick and market-context-refresh, but not the all-caps `POLYMARKET` that previously caused a spurious PASS (via narrative-tracker content). Prior eval (2026-06-14) flagged this as a spurious match and action item 1 recommended patching.

Fix: Remove the `monitor-polymarket` entry from `skills/skill-evals/evals.json` (skill is disabled, no eval value), or tighten the required_pattern to `### monitor-polymarket` only and accept that a disabled skill will always FAIL. Removing the entry is preferred.
