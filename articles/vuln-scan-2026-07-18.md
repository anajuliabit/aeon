## Confirmed findings

### 1. Code-level — Unicode bypass in `_sanitize_name()` prompt-injection defense

- **Severity:** low
- **CWE:** CWE-1039, CWE-176
- **Location:** redacted per PVR — see advisory
- **Channel:** **PVR** — [GHSA-chjm-935c-cx8p](https://github.com/tirth8205/code-review-graph/security/advisories/GHSA-chjm-935c-cx8p) (state=triage)
- **One-line:** the ASCII-only strip in `_sanitize_name()` leaves Unicode Tag characters, bidi overrides, and zero-width joiners intact, so an attacker-controlled symbol name from an untrusted repo passes hidden LLM instructions through MCP into the connected agent — exactly the mitigation `SECURITY.md` names.
- **Reachability:** all 30 MCP tools that pipe through `node_to_dict()`.
- **Existing test coverage:** ASCII 0x00–0x1F only. Zero Unicode-class tests.
- **Fix:** two options in the advisory (allow-list ASCII-printable vs deny-list invisible ranges).
- **PoC:** included in advisory. No network, no privileged inputs.

### 2. Dep CVE audit — 10 prod-path bumps + 3 optional + 5 dev-only

- **Severity:** aggregate — 8× HIGH + 12× MODERATE + 6× LOW across default install
- **Channel:** **public GitHub issue** — [#665](https://github.com/tirth8205/code-review-graph/issues/665)
- **Rationale for issue-not-PR:** every finding is a public advisory, so the disclosure matrix routes them to a public channel. The correct shape is a lockfile-only PR from `uv lock --upgrade-package …`, but `uv` isn't installed in the sandbox runtime and hand-editing `uv.lock` would break the wheel-hash pin the file exists to enforce. Filing an actionable issue with the exact upgrade command is the low-harm substitute.
- **Prod path (recommended):** `mcp` 1.26.0→1.28.1 · `python-multipart` 0.0.22→0.0.31 · `authlib` 1.6.9→1.6.12 · `pyjwt` 2.12.1→2.13.0 · `starlette` 0.52.1→1.3.1 · `urllib3` 2.6.3→2.7.0 · `cryptography` 46.0.5→46.0.7 · `pydantic-settings` 2.13.1→2.14.2 · `requests` 2.32.5→2.33.0 · `idna` 3.11→3.15.
- **Optional-extra path:** `pillow` (18 CVEs, extra=embeddings) · `transformers` (7 CVEs incl HIGH RCE, extra=embeddings) · `torch` (LOW).
- **Dev-only:** `pytest` · `pygments` · `click` · `httplib2` · `setuptools`.
- **Constraint compatibility:** all prod-path fixed-versions fit inside existing `pyproject.toml` constraints. Only `starlette` crosses 0.x→1.x, which needs the maintainer to verify mcp/fastmcp accept it.
