## What was audited and cleared

For readers of this article who want the negative space:

- **CDP evaluate / RCE / injection surface — clean.** Every operator-supplied value that reaches `Runtime.evaluate` (selectors, xpath, text, hrefs, coordinates, keys, pointer deltas, wait predicates) is serialised via `JSON.stringify` before interpolating into the CDP `expression:` string. The `browserFetch` template in `http.ts` does the same. `evaluate()` accepting a raw expression string is the tool's advertised API — the operator's own JS is expected input, not attacker-controlled.
- **No `child_process.exec`, no `shell: true` anywhere.** The only `spawn` in production code is `video-recorder.ts` invoking `ffmpeg` with a fixed argv array (`stdio: [pipe, ignore, pipe]`, no shell), and the two size values that flow into the `-vf scale=…` filter are pre-validated as `Number.isInteger && >= 2`.
- **No Chromium launch surface.** `browser-runtime.ts` sends CDP through `globalThis.ego.sendCDPMessage` — the parent macOS app owns the browser and its profile. No `--user-data-dir`, no `--remote-debugging-port`, no cookie-jar management, no `document.cookie` / `Network.getAllCookies` / `Network.setCookie` handling in the entire source tree. Session-state ownership belongs to the app, not this package.
- **Learning-file loader is textbook.** `learning/index.ts:120-129` (`isLearningNotePath`) requires exactly `notes/<name>.md` with no `.` / `..`; `:218-237` (`relativeSitePath`) rejects backslashes, absolute paths, and any `..` segment, then checks the resolved path starts with the site-root prefix. Nothing to attack here.
- **`update-notice.ts` does no network I/O.** The version probe is a local `ego.getBrowserVersion()` bridge call into the app, comment-documented, with a `noticeSuppressed` env-var opt-out and a bounded `withTimeout` wrapper. No telemetry, no update-fetch URL.
- **`env.ts` `.env` loader** honours `if (process.env[key] === undefined)` — pre-existing environment is never shadowed.
