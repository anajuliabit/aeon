## Summary

**Target:** skill prompt docs — `skills/hacker-news-digest/SKILL.md` + `skills/onboard/SKILL.md`

**Problem:** Both SKILL.md files documented `./notify "$(cat file.md)"` as the way to send multi-line digests. The Claude Code sandbox static analyzer blocks command substitution, so the call never reaches the notify script.
